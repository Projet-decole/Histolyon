Prompts portables de l'équipe et checklist sans IA — peuplé par l'Epic 2.

- `decoupe.md` — pour découper un épic/une capability en stories (rôle Découpeur), avec ou sans BMAD.
- `dev-story.md` — pour implémenter une story avec un assistant IA générique.
- `SANS-IA.md` — pour dérouler une story de bout en bout sans aucun outil IA.
- `review.md` — pour faire relire une PR par un assistant IA générique avant fusion.

Ordre d'usage typique : `decoupe.md` produit les stories → `dev-story.md` ou `SANS-IA.md` en implémente une → `review.md` la relit avant fusion.
