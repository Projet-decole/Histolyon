## Décision proposée
La consultation reste un défilement continu sans onglets. Les sections « Récit / Sources / Commentaires » de la microcopy d’origine ne sont pas reprises. Les sources sont en pied de lecture.

## Sources en conflit
CAP-D2.5 d’origine : pas d’onglets séparant les types de contenu. Microcopy du mode consultation : liste de sections de navigation Récit / Sources / Commentaires.

## Conséquence
Aucun sélecteur de section dans ECR-PIN-CONSULTATION-APPROFONDIE. Le pied « Sources » est une zone du défilement.
