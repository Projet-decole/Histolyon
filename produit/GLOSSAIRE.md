# Glossaire

Termes du produit, avec l’unité qui les définit. Les identifiants de code sont en français sans accent (`pin`, `epoque`, `parcours`, `etape`).

| Terme | Sens | Voir |
|---|---|---|
| Pin | Lieu historique ancré sur la carte, avec un récit | ENT-PIN, CAP-D2.1 |
| Époque | Période fixe de l’histoire de Lyon (10 au total) | ENT-EPOQUE, EPQ-XIXE-SIECLE |
| Slider d’époques | Geste continu pour naviguer dans le temps | CAP-D1.2 |
| Parcours | Suite ordonnée de 7 à 10 pins | ENT-PARCOURS, CAP-D3.3 |
| Étape | Un pin dans un parcours | ENT-ETAPE |
| Pas à pas manuel | Seul mode de parcours du MVP | DEC-05 |
| Récit | Texte narratif d’un pin (tutoiement narratif) | DOC-GUIDE-REDACTION |
| Teaser | Une phrase qui donne envie sans tout dire | DOC-GUIDE-REDACTION |
| Encart | Bloc texte court dans le récit (« Le saviez-vous », citation) | DEC-03 |
| Aperçu rapide | Fiche courte ouverte au tap d’un pin | CAP-D2.4 |
| Consultation approfondie | Écran complet d’un pin | CAP-D2.5 |
| Visionneuse 3D | Vue d’un modèle 3D lié à un pin | CAP-D8.2 |
| Surface persistante | Barre qui reste visible (parcours en cours, bandeau hors-ligne) | DOC-DESIGN-SURFACES |
| Instantané | Contenu embarqué dans l’app au MVP | DEC-04 |
| Tranche verticale | MVP complet de bout en bout, jamais dégradé | DEC-13 |
| S2 | Hors MVP, reporté au second semestre | JAL-S2 |
| Neutralisé | Composant hors MVP cité dans un écran mais non écrit | produit/composants |
| Lugdunum | Nom romain de Lyon (terme lyonnais ou latin à gloser au premier emploi) | DOC-GUIDE-REDACTION |
